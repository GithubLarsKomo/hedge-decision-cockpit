# VI-005 acceptance evidence

- Additional allocation is capped by available extra cash.
- Each exposure allocation is capped by its remaining positive gap after the monthly contribution.
- Zero/overweight gaps receive zero additional allocation.
- When no positive gaps remain, all additional cash is reported as residual.
- Optional hedge context is preserved as metadata only.
- Stable serialization yields byte-equivalent JSON for identical inputs.
- No order, execution, instrument selection, or auto-selection fields are emitted.
