# VI-005 — Extra-cash variants with hedge context

This slice adds deterministic, auditable decision variants for deploying `portfolio.additional_cash_available` after the regular monthly contribution allocation.

The variants operate on strategic exposures only. They do not select ETFs, hedge instruments, contracts, broker orders, or a final winning action.

Supported variants:

- `contribution-only`: keep all additional cash residual.
- `deploy-extra-cash`: allocate additional cash proportionally across remaining positive exposure gaps, capped by both available cash and each gap.
- `deploy-extra-cash-with-hedge-context`: same allocation plus preserved hedge context metadata. Hedge context remains descriptive and is never transformed into execution instructions.

`serializeExtraCashVariants` provides stable key ordering for byte-equivalent JSON from identical semantic inputs.
